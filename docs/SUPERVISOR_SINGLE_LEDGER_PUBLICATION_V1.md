Runtime lifecycle -> actor lifecycle -> bridge -> ledger -> coordinator/group registry is the only publication order. Check every descendant is DONE before invoking any external physical-release verifier. Existing direct reservation tests now take the same monitors. Two new tests cover coordinator absence and concurrent snapshot exclusion. All 19 real ActorRuntime JUnit tests plus unchanged standalone suites are required, no skipped tests. Host-only, not native/compiled guest or physical-release proof. The merged canonical path and independent review remain pending.
