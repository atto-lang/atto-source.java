# Candidate tenant staging credit for authenticated actor DATA

The trusted tenant registry supplies a common IpcIngressBudgetV1 to all ingress endpoints. A non-cloneable-by-API idempotent lease charges one frame and a conservative logical staging allowance (4096 + 8 * wire bytes) before snapshot copies or stream body allocation. Stream admission reads only a bounded length prefix before reservation; a refusal requires closing/discarding that physical stream. Authentication, decoder and ActorRuntime publication run within the lease; every exit releases credit. Existing mailbox ownership accounting remains separate. This is not a measured physical JVM heap bound, allocator proof, timeout or decoder allocation accounting; the trusted decoder must be separately bounded and must not retain staging buffers. Caller-provided frame arrays already exist; only stream ingress prevents initial body allocation before reservation. No guest or full tenant registry integration claim.
