# IPC tenant authorization and retirement

Host-only authorization binds a live ActorRef incarnation to exactly one registered tenant budget. Replacement actors require new explicit authorization; foreign or unregistered domains cannot select a decoder or mailbox. The private authenticated send overload preserves ordinary send preparation and checks tenant identity and retirement inside runtimeLifecycleLock, before mailbox publication and supervisor DATA permit issuance. Tenant retirement uses that same lock, so no IPC publication may commit after retirement returns. Already admitted messages remain governed by the normal mailbox semantics. Local sends remain unchanged. No global cross-process registry, automatic actor tenancy, cryptographic peer key custody integration or physical allocator proof.
