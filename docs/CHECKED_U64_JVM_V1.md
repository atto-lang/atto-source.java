# Experimental checked unsigned JVM scalar profile

Explicit standalone source-to-Java compiler, not the default Graal frontend. Homogeneous u64/uint root functions and closed calls, grouping, checked +,-,*,/. Long stores exact bit patterns; compareUnsigned and divideUnsigned enforce unsigned range before arithmetic. Source, token, node, depth and expanded call-work limits reject unsupported input before code emission. No signed fallback. The generated Java class is compiled with javac and executes real JVM bytecode. Full-width unsigned decimal observer; machine-profile exit 70 for overflow, 71 for division by zero, not the typed Atto Error ABI.

Local OpenJDK 21.0.12.1 / Node 22.16.0: 14/14 focused tests, 24 shared guest executions in -Xint/-Xmixed, 2 additional non-corpus guest executions, 17 invalid-source controls. Mixed mode is not proof of JIT compilation. Exact source/test/corpus blobs matched. The candidate is not integrated with the canonical typed frontend; no Graal Native Image, JDK25, full repository CI or production parity claim. Reconcile existing numeric PR #1329 before canonical integration.

## Checked unsigned division

Unsigned quotient truncates using primitive Long.divideUnsigned, with a precheck for zero and exact E_U64_DIVISION_BY_ZERO diagnostic. The emitter adds the division helper only for source units containing division; ordinary nondivision guest arithmetic and observer remain unchanged. Java's left-to-right evaluation preserves faults before discarded arguments and preceding overflow. No named remainder/modulo admission or general Error/Result ABI claim.

Local exact source blob `93b3fc04cdcbf4774c3f685576b2374959696166`, test blob `03399d7ffa41323c1c52ecaf02b713236218a9f7`: `ATTO_U64_JAVA_DIV_REQUIRED=1 ATTO_U64_JAVA_SOURCE="$PWD/tools/CheckedU64.java" node --test tests/checked-u64-division.test.mjs` passed 8/8 tests/subtests, zero skips, on OpenJDK 21.0.12.1 and Node 22.16.0. 1,296 independently lowered distinct guest programs, batch javac compilation with class declaration renaming only, 2,592 guest method executions in default JVM and -Xint (including 512 generated division executions, 32 boundary executions and 2,048 earlier arithmetic regressions). Per mode, division gives 224 values and 32 exact zero-divisor faults. Two additional standalone CLI guest executions confirmed exit 71 / E_U64_DIVISION_BY_ZERO versus exit 70 / E_U64_OVERFLOW. Five malformed source refusals passed. Missing source, altered hash, invalid strict mode and invalid family fail; unstaged default explicitly skips. The old focused test replaces division refusal with remainder refusal; full original suite not rerun in this batch. No native-image, JIT compilation proof, full repository CI or canonical frontend certification. Historical conformance pins remain unchanged.
